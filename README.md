# Pixel Play
Playful portfolio template for illustrators and content creators.

## What it does
Pixel Play shows work in chunky cards, shares services and process steps, rotates kind words, and collects project notes with a validated contact form.

## Features
1. Sticky pill nav with smooth scroll and mobile menu under 800px
2. Hero with pure CSS shapes, floating stickers and stats
3. Work grid with 6 cards, hover lift and tag filter
4. Services plus process steps plus auto rotating testimonials
5. Contact form with validation plus fun footer with back to top

## Run
1. Open this folder in a terminal
2. Run python3 -m http.server 8000
3. Visit http://localhost:8000 in a browser

## Customize
1. Edit text in index.html to match your name and projects
2. Change solid colors in styles.css inside the root block
3. Swap art shapes by editing the art classes
4. Replace testimonials and stats with your own proof

## Structure
1. index.html holds all sections and copy
2. styles.css holds color, layout, motion and responsive rules
3. script.js holds menu, filter, slider, validation and reveal
4. README.md holds this guide

Built with plain HTML plus CSS plus JS. No build step. Ready for GitHub Pages.
